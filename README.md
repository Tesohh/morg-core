# morg-core
Recreating org features inside Markdown
## Motivation
Org mode is great but we want to keep using the more ubiquitous Markdown.
`morg` recreates the best org mode features, mainly tasks, inside markdown
## LLM Policy
The core allows using LLM tools only for writing tests or with various understanding/debugging/brainstorming uses.
No implementation code can be written with LLMs.
